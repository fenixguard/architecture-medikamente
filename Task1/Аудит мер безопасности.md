# **Аудит мер безопасности**

---

## **Сопоставление процессов с требованиями безопасности**

| **Процесс**            | **Требования**                                                    | **Соответствие** |
|------------------------|-------------------------------------------------------------------|------------------|
| **Запись на приём**    | *Ограничение прав доступа*, **шифрование** данных                 | **Нет**          |
| **Оплата услуг**       | *Логирование действий*, **шифрование** при передаче               | **Частично**     |
| **Обработка анализов** | **Шифрование** файлов, *разграничение прав доступа*               | **Нет**          |

---

### **Проблемные зоны**

1. **Нет контроля доступа**  
   *Данные пациентов доступны без ролевого разграничения.*
2. **Недостаточная защита файлов**  
   *Информация хранится в открытом виде (Excel, PDF).*
3. **Отсутствует мониторинг и аудит**  
   *Действия с данными не отслеживаются и не регистрируются.*
4. **Ручная обработка**  
   *Высокий риск утечек и человеческих ошибок.*

---

## **Повышение уровня безопасности данных**

### **Методы защиты**

| **Тип данных**  | **Рекомендуемые меры**                                |
|-----------------|--------------------------------------------------------|
| **ФИО**         | *Шифрование*, **ограничение доступа**                  |
| **Контакты**    | *Обезличивание*, **шифрование**                        |
| **Медицинские** | *Обфускация*, **тегирование**                          |
| **Финансовые**  | **Шифрование**, *токенизация*                          |

---

## **Разработка системы тегирования данных**

#### **Основные категории тегов**
- `PII` *(персональные данные)*  
- `Sensitive` *(чувствительные данные)*  
- `Confidential` *(конфиденциальные данные)*  
- `Medical` *(медицинская информация)*

#### **Инструмент для тегирования**
> **DataGrail** — оптимальный выбор для MVP:
> - Позволяет отслеживать движение данных в режиме реального времени.
> - Имеет готовые коннекторы для PostgreSQL.

---

## **Рекомендации по улучшению**

### **Шифрование данных**
- Применить *Transparent Data Encryption (TDE)* для базы данных.
- Использовать *шифрование* на уровне файлового хранилища.

### **Обезличивание данных**
- Удалять идентификаторы при аналитической обработке.
- Применять *псевдонимизацию* для критичных полей.

### **Ограничение доступа**
- Внедрить **ролевую модель** (*RBAC*).
- Активировать **двухфакторную аутентификацию**.

---

> **Важно:** Реализация перечисленных мер не только повысит уровень защиты персональных данных, но и сократит риски потенциальных утечек, соблюдая требования законодательства по безопасности информации.
